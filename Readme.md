# Medical Record Management System

## Description
A system to securely store, manage, and access patient medical records, including personal details, medical history, diagnoses, and treatment information.

## Features
- Patient details management
- Medical history maintenance
- Diagnosis and treatment records
- Easy access to patient information
- Secure record management

## Objective
To simplify medical record management and improve the accessibility and organization of patient information.
